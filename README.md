# 📌 Pin Caption Generator

> Upload any image and instantly get an AI-generated Pinterest caption with hashtags.

🌐 **Live Site:** [pin-caption-generator.onrender.com](https://pin-caption-generator.onrender.com)

! [Pin Caption Generator](screenshot.png)

---

## ✨ Features

- 🖼️ Upload any image directly from your device
- 🤖 AI analyzes the image and generates a Pinterest-style caption
- #️⃣ Automatically includes 3–5 relevant hashtags
- 💬 Warm, engaging tone that sounds like a real Pinterest creator
- ⚡ Fast results powered by Claude's vision API

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | HTML |
| Backend | Python, Flask |
| AI | Anthropic Claude API (Vision) |
| Image Processing | Pillow (PIL) |
| Deployed | Render |

---

## 🧠 How It Works

1. User uploads an image via the web interface
2. The image is resized and converted to base64
3. Claude's vision model analyzes the image
4. A Pinterest-style caption + hashtags are returned instantly
